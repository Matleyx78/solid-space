# Chiusura della tappa

Si legge insieme al nucleo, [AGENTS.md](../../AGENTS.md), quando ti chiedono la
pull request di chiusura della tappa, quando il ramo è `docs/chiusura-X.Y`,
oppure quando il lavoro tocca `docs/rilasci/`. Di norma la fa Codex.

Le regole non si ripetono qui, stanno in due posti:

- che cosa fa la pull request di chiusura, quando si apre e su quale ramo:
  [LAVORO-IN-PARALLELO.md](../LAVORO-IN-PARALLELO.md), sezione 8, "Chiudere la
  tappa";
- quando una tappa è chiusa e che cosa segue (tabella, tag, richieste):
  [ROADMAP.md](../ROADMAP.md), "Chiudere una tappa".

È una pull request di soli documenti: non si compila in locale, la verifica la fa
la CI (decisione del 2026-11-03, [DECISIONI.md](../DECISIONI.md)). La prova
manuale, il merge e la versione li fa il responsabile.
